# Mew RPG: imagens públicas

Imagens usadas no fórum **Mew RPG** (mewrpg.forumeiros.com). Este repositório é
**público de propósito**: o fórum precisa de um endereço aberto para cada imagem.
Aqui só entram imagens já publicadas no fórum. Nada de dados de membros, senhas
ou arquivos de trabalho (os originais ficam no repositório privado do backup).

Endereço base: `https://lucasfonseca42-droid.github.io/mewrpg-imagens/`

| Pasta | Conteúdo |
|---|---|
| `cidades/` | Imagem de cada cidade dos pop-ups da Home, recorte 16:9, 736 x 414 px, JPEG |
| `regioes/` | Imagem de cada card de região da Home, recorte 16:9, 736 x 414 px, JPEG |
| `locais/` | Imagem de cada local dos pop-ups da Home (fora as cidades), recorte 16:9, 736 x 414 px, JPEG |
| `pontos/` | Imagens dos pontos de interesse das postagens de local (`<regiao>-<ponto>.webp`) |
| `icones/` | Ícones do fórum; `favicon-mew-128.png` é o ícone da aba do navegador (rosto do Mew num círculo roxo, 128 x 128 px, PNG) |

Regras: nomes em minúsculas e sem espaço (`cidade-liyue.jpg`); nunca reutilize um
nome com outra imagem sem avisar (o navegador guarda cache); para trocar uma
imagem, use um nome novo e atualize a Home.
